# Chart families

Braven Charts ships ten native Flutter chart families: line, area, range area,
bar, scatter, pie, donut, candlestick, polar, and radial.

- [Compare all chart families](https://braven-pvm.github.io/braven_charts/?page=chart-types)
- [Inspect the capability matrix](https://github.com/braven-pvm/braven_charts/blob/master/doc/feature_matrix.md)
- [Explore the visual gallery](https://braven-pvm.github.io/braven_charts/?page=gallery)

Each family page in the showcase combines a rendered example with focused
configuration guidance.
