# Get started

Start with `BravenChartPlus` when you want typed series and explicit chart
configuration. Use `BravenChart` when a concise grammar is the better fit.

- [Build your first chart](https://braven-pvm.github.io/braven_charts/?page=docs)
- [Choose a chart family](https://braven-pvm.github.io/braven_charts/?page=chart-types)
- [Read the full getting-started guide](https://github.com/braven-pvm/braven_charts/blob/master/doc/api_reference.md)
- [Open the package on pub.dev](https://pub.dev/packages/braven_charts)

The public API is split into the core `braven_charts` library and the opt-in
`braven_charts_fluent` modifiers.
