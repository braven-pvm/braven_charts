Label Color

What color should the value label use by default?

Match series color (default)

Labels inherit the series color automatically. Each series is self-consistent — labels, markers, and lines share the same color. Zero config needed.

Fixed dark (#333)

All labels always charcoal regardless of series color. More readable against light backgrounds. Consistent look across multi-series charts.

Explicit color field (null → series color)

Config has a labelColor field. When null it falls back to the series color — so default behaviour is the same as option A, but overridable per-series.
