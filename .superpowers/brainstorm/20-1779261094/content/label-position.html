Data Point Label Position

Where should the value label sit relative to the data point marker?

Above (default)

Label sits above the marker. Works well on most charts. Simple and predictable. Most common convention in sports/science charting.

Below

Label sits below the marker. Useful when the top of the chart is tight or when labels would overlap a legend above.

Configurable — above / below / left / right

Enum with four positions + a pixel offset to fine-tune. Default: above. All four positions available for edge cases or dense charts.
