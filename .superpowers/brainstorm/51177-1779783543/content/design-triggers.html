Design — Section 3: Selection Triggers & Files Changed

How the three input paths feed into a single swap handler, and what files touch.

1. Three Paths → One Handler

Legend tap

User taps a series name in the legend panel. Legend widget fires onSeriesTap(seriesId) → chart state's _handleSeriesSelected().

Data point tap

User taps a marker or series line. Existing tap recognition (EventHandlerManager) resolves to a series → fires same _handleSeriesSelected().

Programmatic

BravenChartController.selectSeries(id) calls into chart state directly via the same handler. No UI event required.

↓ all three converge ↓
_handleSeriesSelected(String seriesId)
↓

If axis is in overflow

→ Demote last visible on same side
→ Promote selected axis to slot N
→ setState() → repaint
→ Fire onAxisSwapped callback

If axis already visible (or hidden intentionally)

→ No axis swap
→ Series still marked selected
→ onSeriesSelected callback fires
→ Deselect on second tap

Tapping an already-selected series calls _handleSeriesDeselected() — triggers revert if mode is revert, no-op if sticky.
