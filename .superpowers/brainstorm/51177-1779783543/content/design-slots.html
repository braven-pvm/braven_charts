Declaration order = priority. The first series declared that claims right gets slot 1, second gets slot 2, etc. Overflow axes participate in Y-normalization but paint nothing.

In sticky mode, selecting a second overflow series triggers a second swap — the lowest-priority visible is bumped again. The user builds up their preferred visible set naturally through interaction.

4. What "hidden" means for normalization

Overflow axes are not painted — no tick labels, no axis line. But they are still included in bounds computation, so their series lines are still correctly scaled relative to visible axes. The series line itself is always drawn regardless of slot visibility.
