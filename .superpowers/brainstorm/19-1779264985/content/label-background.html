Label Background

Should labels have a background to improve readability over crossing lines?

No background (plain text)

Simplest. Matches the reference screenshot style. Can get hard to read when labels overlap crossing series lines, but works well on clean single-series charts.

White pill background

Rounded white capsule behind each label. Cuts through crossing lines cleanly. Slightly more visual weight — good for dense multi-series charts.

// No background (default)
DataPointLabelConfig(
  background: null,
)

// White pill
DataPointLabelConfig(
  background: Colors.white,
  backgroundOpacity: 0.85,
)

Optional — background color field

Null by default (no background). Set any color + opacity for a pill. Gives full control — white, chart background color, or a tinted match to the series.
