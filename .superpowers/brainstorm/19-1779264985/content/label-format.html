Label Content & Formatting

What does the label show, and how is it formatted?

Y-value only

Auto-formats: integer if whole number, 1–2 decimals otherwise. showUnit: false by default. Cleanest look — matches the reference screenshot.

Y-value + unit suffix

Appends series.unit to each label. Enabled via showUnit: true. Good when the chart has no axis label or when units differ per series.

DataPointLabelConfig(
  show: true,
  // default: Y-value, auto-formatted
  showUnit: false,
  // full override:
  formatter: (point) =>
    '${point.y.toInt()} bpm',
)

All three — value-only default, showUnit toggle, custom formatter

Default shows Y-value only. showUnit: true appends the series unit. formatter: (point) → String overrides everything. My recommendation.
