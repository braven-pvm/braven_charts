# Grammar V2.0 — Close the Emission Gaps — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the V1 grammar so the three most common charts it currently refuses can be authored *and* round-trip-emitted: non-trend reference annotations, chart-level options (grid/title/legend), and per-mark data-point markers + inline labels.

**Architecture:** Each addition is a full vertical slice through the existing V1 pipeline — a new `Mark`/`PlotSpec` field, its `lower()` mapping onto the config it already lowers to, a `BravenChart` facade verb, config- and artifact-parity tests, and grammar-source emission — with **no change to the render pipeline or config classes**. Marks/PlotSpec stay `copyWith`-free (adding `copyWith` would make them config-shaped and trip enforcement).

**Tech Stack:** Dart ≥3.9 / Flutter ≥3.35; the grammar layer under `lib/src/grammar/` + the emitter `lib/src/source/chart_grammar_source_generator.dart`.

```dart
// Reference marks: literal-coordinate marks that lower to annotations, like TrendMark.
final class ThresholdMark<T> extends Mark<T> {
  const ThresholdMark({required this.value, this.axis = ChartAxis.y,
    super.id, super.name, super.color, this.label, this.dashPattern, this.strokeWidth});
  final double value; final ChartAxis axis; final String? label;
  final List<double>? dashPattern; final double? strokeWidth;
}
final class BandMark<T> extends Mark<T> {   // -> RangeAnnotation
  const BandMark({required this.start, required this.end, this.axis = ChartAxis.y,
    super.id, super.name, super.color, this.label, this.opacity});
  final double start; final double end; final ChartAxis axis; final String? label; final double? opacity;
}
final class PointMark<T> extends Mark<T> {  // -> PointAnnotation (a marked coordinate, NOT the scatter geom)
  const PointMark({required this.x, required this.y,
    super.id, super.name, super.color, this.label, this.markerRadius, this.markerShape});
  final double x; final double y; final String? label; final double? markerRadius; final SeriesMarkerShape? markerShape;
}
enum ChartAxis { x, y }   // if an equivalent enum already exists in the models, reuse it and drop this
```
